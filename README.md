A responsive college club website built using HTML and CSS as part of the Web Development Day 05 assignment.

## About the Project

Campus Connect is a college club website designed to share information about the club, its activities, events, and registration process.

## Pages

- `index.html` – Home page
- `about.html` – About the club
- `registration.html` – Club registration form
- `contact.html` – Contact information

## Technologies Used

- HTML5
- CSS3
- CSS Variables
- Responsive Web Design

## Features

- Responsive layout for desktop and mobile
- Navigation between multiple pages
- Registration form
- Consistent typography and colours
- Reusable CSS classes and selectors
